## 字段说明

- **商品名称**: 抖音电商商品标题（来自 raw_douyin_ec_items.title, 真实电商商品）
- **分类**: 一级类目 / 二级类目 / 叶子类目
- **过去爆款原因分析**: 叶子类目前 5% 且持续 ≥ 5 天 = 过去爆款; 原因列出榜单 / 持续天数 / 动量
- **预期是否属于爆款**: V1 规则总分 ≥ 0.70 = 是; < 0.70 = 否
- **预测原因**: V1 规则 7 维贡献拆解（销量 30% / 动量 20% / 好评 10% / 达人 10% / 店铺 10% / 榜单 10% / 佣金 10%）
- **各平台数据表现**: 该商品在抖音电商叶子类目内的销量排名 + 同类目在小红书 / 视频号的种草热度（用叶子类目关键词在社媒标题里匹配）

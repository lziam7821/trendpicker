## 字段说明

- **商品名称**：抖音电商商品标题 / 小红书笔记标题 / 微信视频号视频标题
- **分类**：抖音电商的「一级类目 / 二级类目 / 叶子类目」；社媒源无类目归属
- **过去爆款原因分析**：叶子类目前 5% 且持续 ≥ 5 天 = 过去爆款；原因列出关键指标（榜单、持续天数、动量）
- **预期是否属于爆款**：V1 规则总分 ≥ 0.70 = 是；< 0.70 = 否
- **预测原因**：V1 规则 7 维贡献拆解（销量 30% / 动量 20% / 好评 10% / 达人 10% / 店铺 10% / 榜单 10% / 佣金 10%）；社媒源走 2 维（互动 70% + 类目命中 30%）
- **各平台数据表现**：3 个平台的全局聚合摘要（抖音电商总月销/好评/类目分布、小红书总互动、视频号总点赞）

## 规则与流程合规性

- 落库链路：外部 API → 原始响应存 raw/ 文件 → 解析 → INSERT/UPSERT 到 raw_xxx 表 → 提交 fetch_log
- 分析链路（本报告）：SELECT FROM product_predictions → 6 字段渲染 → Markdown 报告
- 本报告未触及任何外部 API；所有数据均从 `trendpicker.db` 读取
- 凭据 TIKHUB_API_KEY / JUSTONEAPI_API_KEY 已在 `credentials.py` 的 CREDENTIAL_NAMES 中登记，落库时通过环境变量读取，未写入版本库
